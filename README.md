# Justin Garey Personal Website & Portfolio

I wanted a place to list my projects, write blogs, and host my web games. This is it!

## Creation

```bash
npx create-next-app@latest JustinGareyWebsite --typescript
```

## Usage

Run Development Server
```bash
npm run dev
```

Run Production Build
```bash
npm run build
```

Start Production Server
```bash
npm run start
```

## Installed Packages

[Tailwind](https://tailwindcss.com/docs/installation/framework-guides/nextjs):
```bash
npm install tailwindcss @tailwindcss/postcss
```

Next.js 
```bash
npm install next react react-dom
```

React Markdown
```bash
npm install react-markdown
```

GitHub Flavored Markdown
```bash
npm install react-gfm
```

LaTeX Support for Markdown
```bash
npm install remark-math rehype-katex katex
```

Carousel with React Slick
```bash
npm install react-slick
npm i --save-dev @types/react-slick
npm install slick-carousel
```

Icons for React
```bash
npm install react-icons
```
